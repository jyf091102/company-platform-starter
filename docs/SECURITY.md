# Security

## 发布前清单

- 使用独立的开发、预发布和生产项目。
- 密钥只存于 Cloudflare/GitHub Secrets，不写入代码、示例、日志或 URL。
- 为所有业务表启用 RLS，并用匿名、普通用户、员工三种身份测试。
- 限制上传类型、大小与访问期限；敏感材料使用私有存储桶。
- 启用 MFA、分支保护、依赖更新、secret scanning 和审计日志。
- 对认证、客服和写接口添加速率限制与滥用检测。
- 在处理个人信息前完成隐私、数据保留和跨境传输评估。

发现漏洞时，请通过仓库的 GitHub Security Advisory 私下报告，不要在公开 Issue 中提交凭据或个人信息。
